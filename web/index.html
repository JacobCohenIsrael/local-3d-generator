Make it yours

!

Names this asset in history. With Automatic preset it does not guide shape or color; your photos do. The optional Strata settings planner also receives this name as subject context.

!

Balanced uses 30 sampling steps and a lower extraction resolution. Detailed uses 50 steps and a higher resolution, with more generation work and possible memory use. It may capture finer shape, but does not guarantee better likeness. Triangle budget controls the final exported density separately. The optional Strata planner may choose different sampling settings.

!

Objects and People use different foreground removal models. A clean silhouette helps both shape generation and photo color alignment. Keep background is for already isolated images; scenery left in a photo can become part of the mesh. Existing transparency is retained.

!

Photo color projects selected reference images onto the final reduced mesh. It adds UVs, a color image and baking work; it does not add geometric detail. Untextured skips photo baking and exports geometry without a photo color map. Neither option generates a rig or PBR maps.

Photo colors use an approximate angle fit. Choose how unseen areas are shown below.

!

With photo color enabled, Neutral gray makes areas without trusted photo color easy to spot. Extend nearby colors estimates these areas from the nearest observed surface, reducing gray gaps but sometimes smearing details. It does not recover unseen texture or change geometry. Photo coverage excludes the estimated fill.

Estimated fill matches nearby surface colors; it does not recover unseen detail. Coverage still counts photo color only.

!

Sets the exported model's vertical height in meters, from 0.1 to 20. Blender scales it uniformly, centers it horizontally and grounds its base. This changes scene size, not proportions, triangle count or generation detail.

!

Caps the target triangle count by simplifying the generated mesh before color baking and export. Lower counts reduce geometry to draw and store, but can lose silhouette detail, thin parts and smooth curves. 500–2,500 is very coarse; 5,000–10,000 retains more shape. This does not reduce neural generation steps or texture size, and runtime performance also depends on materials, textures and your scene. See the result for the actual triangle count.

Advanced options
!

With photo color enabled, 1024 × 1024 stores more color pixels; 512 × 512 uses one quarter as many pixels with less room for fine color detail. It changes the texture, not mesh density, and cannot add detail missing from the source images. Unity import settings also affect texture memory.

!

A second seed is tried only when the first result fails geometric checks, such as a collapsed slab. It can cost another generation, with at most two attempts total. It does not automatically retry crashes or memory failures, and cannot judge resemblance.

!

Automatic preset chooses bounded sampling settings without a language model. Strata uses a local model and input metadata to choose sampling settings, adding planning time and RAM use. It does not directly build the mesh. Extra-photo view recognition uses Strata separately, even with Automatic preset.

!

Allows intentionally thin subjects to pass the collapsed-slab check. It does not flatten the mesh or select a low-poly style. Leave it off for solid objects so accidental flat results can still be rejected.

Extra photos always use Strata vision for selection. The settings planner is a separate choice.
